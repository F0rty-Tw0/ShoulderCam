# Changelog

Player-friendly release notes for ShoulderCam. This file covers the current 1.x series; older series live in [archive/changelog/](archive/changelog/).

All releases: **1.1.x (current)** · [1.0.x](archive/changelog/1.0.md) · [0.1.x](archive/changelog/0.1.md)

## [Unreleased]

- Added an Indoors camera: its own zoom distance, shoulder and tilt settings while you are inside buildings and caves. Off by default; turn it on in the new Indoors tab.

## [1.1.0] - 2026-11-04

- Added `/shc toggle` and `/shc swap` chat commands (usable in macros) that turn the camera on or off and swap the shoulder.
